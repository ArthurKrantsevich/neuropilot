## Was ist das

Links sitzt **Unit**, das Maskottchen des Kanals: ein lebendiger 3D-Roboter aus Würfeln. Er sitzt auf einem Baumstamm am Rand einer schwebenden Insel, baumelt mit den Beinen, folgt dem Cursor mit seinem Bildschirmgesicht, schaut auf die Karte unter der Maus und zeigt ihr Thema. Ein Klick auf ihn – und er reagiert mit einer Emotion.

Rechts **alle Komponenten aus den Videos** als lückenloses Mauerwerk:

- **eingeklappt** – Nummer, Titel, kurze Beschreibung;
- **ausgeklappt** – eine Live-Demo direkt auf der Seite;
- **`</>` Code** – Fenster mit den Dateien der Komponente, **⤓ .zip** – Quellen als ein Archiv laden;
- **▲ / ▼** – Komponente bewerten;
- **🔒 noch nicht erschienen** – bis das Video veröffentlicht ist, bleibt die Karte gesperrt: „Unit baut dieses Widget noch“ und ein Countdown. Sie öffnet sich von selbst.

Jede Karte hat einen Direktlink: `https://arthurkrantsevich.github.io/neuropilot/#<id>` – so verweisen die Videobeschreibungen auf die Komponente.

## Aufbau

| Teil | Wo | Inhalt |
|---|---|---|
| Startseite | [`src/home/BentoHome.tsx`](src/home/BentoHome.tsx) | 3D-Szene mit eigener Uhr (nur sie rendert mit 60 fps) + Kartenspalte |
| Karte | [`src/home/Card.tsx`](src/home/Card.tsx) | ein-/ausgeklappt, Code-Fenster, Bewertungen, gesperrter Zustand mit Countdown |
| Mauerwerk | [`src/home/Masonry.tsx`](src/home/Masonry.tsx) | jede Karte kommt in die kürzeste Spalte; weiche Übergänge |
| Veröffentlichungen | [`src/home/releases.ts`](src/home/releases.ts) | wann eine Komponente öffnet; bei jedem Upload kommt eine Zeile dazu |
| Komponenten | [`src/gallery/`](src/gallery) | alle Demos aus den Videos; ihre Quellen landen vor dem Build in `public/code` |
| Unit und Welt | [`src/studio/`](src/studio) | Voxel-Baukasten, Rig, Bewegungsbibliothek – derselbe Code, der die Videos rendert |

Units Code wurde für Video (Remotion) geschrieben, wo ein Frame die Frame-Nummer ist. Auf der Website ersetzt [`src/shims/remotion.tsx`](src/shims/remotion.tsx) das durch die echte Browserzeit – Unit bewegt sich genau wie in den Videos.

## Lokal starten

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # statische Seite in out/ (vorher werden die Quellen nach public/code kopiert)
./deploy.sh        # auf GitHub Pages veröffentlichen (Branch gh-pages)
```
