## What it is

On the left is **Unit**, the channel's mascot: a live 3D robot made of cubes. He sits on a log at the edge of a floating island, swings his legs, follows your cursor with his screen-face, looks at the card you hover and shows its theme on his screen. Click him and he reacts with an emotion.

On the right are **all the components from the videos** in a gap-free masonry:

- **collapsed** — number, title, short description;
- **expanded** — a live demo you can play with right on the page;
- **`</>` Code** — a window with the component's files, **⤓ .zip** — download the sources as one archive;
- **▲ / ▼** — rate the component;
- **🔒 not out yet** — until its video is published the card is locked: “Unit is still building this widget” and a countdown. It unlocks by itself.

Every card has a direct link: `https://arthurkrantsevich.github.io/neuropilot/#<id>` — that's how video descriptions point to a component.

## How it works

| Part | Where | What's inside |
|---|---|---|
| Home | [`src/home/BentoHome.tsx`](src/home/BentoHome.tsx) | 3D scene with its own clock (only it renders at 60 fps) + the card column |
| Card | [`src/home/Card.tsx`](src/home/Card.tsx) | collapsed / expanded, code window, votes, locked state with a countdown |
| Masonry | [`src/home/Masonry.tsx`](src/home/Masonry.tsx) | each card goes to the shortest column; moves are smooth, nothing is re-created |
| Releases | [`src/home/releases.ts`](src/home/releases.ts) | when a component unlocks; a line is added with every upload |
| Components | [`src/gallery/`](src/gallery) | every demo from the videos; their sources go to `public/code` before the build |
| Unit & world | [`src/studio/`](src/studio) | voxel builder, rig, motion library — the same code that renders the videos |

Unit's code was written for video (Remotion), where a frame is the video's frame number. On the site [`src/shims/remotion.tsx`](src/shims/remotion.tsx) replaces it with live browser time, so Unit moves exactly like in the videos.

## Run it locally

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # static site in out/ (component sources are copied to public/code first)
./deploy.sh        # publish to GitHub Pages (gh-pages branch)
```
