## Qué es

A la izquierda está **Unit**, la mascota del canal: un robot 3D vivo hecho de cubos. Está sentado en un tronco al borde de una isla flotante, balancea las piernas, sigue el cursor con su pantalla-cara, mira la tarjeta que señalas y muestra su tema. Haz clic en él y reaccionará con una emoción.

A la derecha, **todos los componentes de los vídeos** en un mosaico sin huecos:

- **plegada** — número, título y descripción corta;
- **desplegada** — una demo viva que puedes tocar en la misma página;
- **`</>` Código** — ventana con los archivos del componente, **⤓ .zip** — descarga las fuentes en un archivo;
- **▲ / ▼** — valora el componente;
- **🔒 aún no publicado** — hasta que sale el vídeo, la tarjeta está bloqueada: «Unit todavía está construyendo este widget» y una cuenta atrás. Se desbloquea sola.

Cada tarjeta tiene enlace directo: `https://arthurkrantsevich.github.io/neuropilot/#<id>` — así enlazan las descripciones de los vídeos.

## Cómo funciona

| Parte | Dónde | Qué contiene |
|---|---|---|
| Inicio | [`src/home/BentoHome.tsx`](src/home/BentoHome.tsx) | escena 3D con su propio reloj (solo ella se dibuja a 60 fps) + columna de tarjetas |
| Tarjeta | [`src/home/Card.tsx`](src/home/Card.tsx) | plegada / desplegada, ventana de código, votos, estado bloqueado con cuenta atrás |
| Mosaico | [`src/home/Masonry.tsx`](src/home/Masonry.tsx) | cada tarjeta va a la columna más corta; los movimientos son suaves |
| Estrenos | [`src/home/releases.ts`](src/home/releases.ts) | cuándo se abre un componente; se añade una línea en cada subida |
| Componentes | [`src/gallery/`](src/gallery) | todas las demos de los vídeos; sus fuentes se copian a `public/code` antes de compilar |
| Unit y su mundo | [`src/studio/`](src/studio) | constructor de vóxeles, rig, biblioteca de movimientos: el mismo código que renderiza los vídeos |

El código de Unit se escribió para vídeo (Remotion), donde el fotograma es el número de fotograma. En el sitio [`src/shims/remotion.tsx`](src/shims/remotion.tsx) lo sustituye por el tiempo real del navegador, así Unit se mueve igual que en los vídeos.

## Ejecutar en local

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # sitio estático en out/ (antes se copian las fuentes a public/code)
./deploy.sh        # publicar en GitHub Pages (rama gh-pages)
```
