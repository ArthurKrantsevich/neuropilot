## De quoi s'agit-il

À gauche, **Unit**, la mascotte de la chaîne : un robot 3D vivant fait de cubes. Il est assis sur un tronc au bord d'une île flottante, balance ses jambes, suit ton curseur avec son visage-écran, regarde la carte survolée et en affiche le thème. Clique dessus : il réagit avec une émotion.

À droite, **tous les composants des vidéos** dans une mosaïque sans trous :

- **repliée** — numéro, titre, courte description ;
- **dépliée** — une démo vivante à manipuler sur la page ;
- **`</>` Code** — fenêtre avec les fichiers du composant, **⤓ .zip** — télécharger les sources en une archive ;
- **▲ / ▼** — noter le composant ;
- **🔒 pas encore sorti** — tant que la vidéo n'est pas publiée, la carte est verrouillée : « Unit construit encore ce widget » et un compte à rebours. Elle s'ouvre toute seule.

Chaque carte a un lien direct : `https://arthurkrantsevich.github.io/neuropilot/#<id>` — c'est ainsi que les descriptions des vidéos y renvoient.

## Comment c'est fait

| Partie | Où | Contenu |
|---|---|---|
| Accueil | [`src/home/BentoHome.tsx`](src/home/BentoHome.tsx) | scène 3D avec sa propre horloge (seule elle est rendue à 60 i/s) + colonne de cartes |
| Carte | [`src/home/Card.tsx`](src/home/Card.tsx) | repliée / dépliée, fenêtre de code, votes, état verrouillé avec compte à rebours |
| Mosaïque | [`src/home/Masonry.tsx`](src/home/Masonry.tsx) | chaque carte va dans la colonne la plus courte ; déplacements fluides |
| Sorties | [`src/home/releases.ts`](src/home/releases.ts) | quand un composant s'ouvre ; une ligne est ajoutée à chaque mise en ligne |
| Composants | [`src/gallery/`](src/gallery) | toutes les démos des vidéos ; leurs sources vont dans `public/code` avant le build |
| Unit et son monde | [`src/studio/`](src/studio) | constructeur de voxels, rig, bibliothèque de mouvements — le même code qui rend les vidéos |

Le code d'Unit a été écrit pour la vidéo (Remotion), où une image est son numéro d'image. Sur le site, [`src/shims/remotion.tsx`](src/shims/remotion.tsx) le remplace par le temps réel du navigateur : Unit bouge comme dans les vidéos.

## Lancer en local

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # site statique dans out/ (les sources sont d'abord copiées dans public/code)
./deploy.sh        # publier sur GitHub Pages (branche gh-pages)
```
