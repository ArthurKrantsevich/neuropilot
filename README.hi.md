## यह क्या है

बाईं ओर है **Unit**, चैनल का मैस्कॉट: क्यूब्स से बना एक जीवंत 3D रोबोट। वह तैरते द्वीप के किनारे एक लट्ठे पर बैठा पैर झुलाता है, अपनी स्क्रीन-चेहरे से कर्सर का पीछा करता है, जिस कार्ड पर आप माउस ले जाते हैं उसे देखता है और उसकी थीम दिखाता है। उस पर क्लिक करें — वह भावना से जवाब देगा।

दाईं ओर हैं **वीडियो के सभी कंपोनेंट**, बिना खाली जगह वाले लेआउट में:

- **बंद** — नंबर, शीर्षक, छोटा विवरण;
- **खुला** — लाइव डेमो, जिसे पेज पर ही चलाया जा सकता है;
- **`</>` कोड** — कंपोनेंट की फ़ाइलों वाली विंडो, **⤓ .zip** — सोर्स एक आर्काइव में डाउनलोड करें;
- **▲ / ▼** — कंपोनेंट को रेटिंग दें;
- **🔒 अभी आया नहीं** — जब तक वीडियो प्रकाशित नहीं होता, कार्ड बंद रहता है: “Unit अभी यह विजेट बना रहा है” और उलटी गिनती। यह अपने आप खुल जाता है।

हर कार्ड का सीधा लिंक है: `https://arthurkrantsevich.github.io/neuropilot/#<id>` — वीडियो के विवरण इसी तरह कंपोनेंट तक ले जाते हैं।

## यह कैसे बना है

| भाग | कहाँ | अंदर क्या है |
|---|---|---|
| होम | [`src/home/BentoHome.tsx`](src/home/BentoHome.tsx) | अपनी घड़ी वाला 3D दृश्य (60 fps पर सिर्फ़ वही बनता है) + कार्ड का कॉलम |
| कार्ड | [`src/home/Card.tsx`](src/home/Card.tsx) | बंद / खुला, कोड विंडो, वोट, उलटी गिनती वाली बंद अवस्था |
| लेआउट | [`src/home/Masonry.tsx`](src/home/Masonry.tsx) | हर कार्ड सबसे छोटे कॉलम में जाता है; बदलाव मुलायम |
| रिलीज़ | [`src/home/releases.ts`](src/home/releases.ts) | कंपोनेंट कब खुलेगा; हर अपलोड पर एक पंक्ति जुड़ती है |
| कंपोनेंट | [`src/gallery/`](src/gallery) | वीडियो के सभी डेमो; बिल्ड से पहले उनका सोर्स `public/code` में जाता है |
| Unit और दुनिया | [`src/studio/`](src/studio) | वॉक्सेल बिल्डर, रिग, मूवमेंट लाइब्रेरी — वही कोड जो वीडियो बनाता है |

Unit का कोड वीडियो (Remotion) के लिए लिखा गया है, जहाँ फ़्रेम उसका नंबर होता है। साइट पर [`src/shims/remotion.tsx`](src/shims/remotion.tsx) इसे ब्राउज़र के असली समय से बदल देता है, इसलिए Unit वीडियो जैसा ही चलता है।

## अपने कंप्यूटर पर चलाएँ

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # out/ में स्टैटिक साइट (पहले सोर्स public/code में कॉपी होता है)
./deploy.sh        # GitHub Pages पर प्रकाशित करें (gh-pages ब्रांच)
```
