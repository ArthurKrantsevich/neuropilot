## Apa ini

Di kiri ada **Unit**, maskot kanal: robot 3D hidup dari kubus. Ia duduk di batang kayu di tepi pulau melayang, mengayunkan kaki, mengikuti kursor dengan layar-wajahnya, menatap kartu yang kamu sorot dan menampilkan temanya. Klik dia — ia membalas dengan emosi.

Di kanan ada **semua komponen dari video** dalam susunan tanpa celah:

- **tertutup** — nomor, judul, deskripsi singkat;
- **terbuka** — demo hidup yang bisa dicoba langsung di halaman;
- **`</>` Kode** — jendela berisi file komponen, **⤓ .zip** — unduh sumber dalam satu arsip;
- **▲ / ▼** — beri nilai komponen;
- **🔒 belum rilis** — sampai videonya terbit, kartu terkunci: “Unit masih merakit widget ini” dan hitung mundur. Terbuka sendiri.

Setiap kartu punya tautan langsung: `https://arthurkrantsevich.github.io/neuropilot/#<id>` — begitulah deskripsi video menautkannya.

## Cara kerja

| Bagian | Lokasi | Isi |
|---|---|---|
| Beranda | [`src/home/BentoHome.tsx`](src/home/BentoHome.tsx) | adegan 3D dengan jamnya sendiri (hanya ia yang digambar 60 fps) + kolom kartu |
| Kartu | [`src/home/Card.tsx`](src/home/Card.tsx) | tertutup / terbuka, jendela kode, suara, status terkunci dengan hitung mundur |
| Susunan | [`src/home/Masonry.tsx`](src/home/Masonry.tsx) | tiap kartu masuk ke kolom terpendek; perpindahan halus |
| Rilis | [`src/home/releases.ts`](src/home/releases.ts) | kapan komponen terbuka; satu baris ditambah tiap unggahan |
| Komponen | [`src/gallery/`](src/gallery) | semua demo dari video; sumbernya disalin ke `public/code` sebelum build |
| Unit & dunianya | [`src/studio/`](src/studio) | pembuat voxel, rig, pustaka gerakan — kode yang sama yang merender video |

Kode Unit ditulis untuk video (Remotion), di mana frame adalah nomor frame. Di situs, [`src/shims/remotion.tsx`](src/shims/remotion.tsx) menggantinya dengan waktu nyata browser, jadi Unit bergerak persis seperti di video.

## Jalankan secara lokal

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # situs statis di out/ (sumber komponen disalin ke public/code dulu)
./deploy.sh        # terbitkan ke GitHub Pages (branch gh-pages)
```
