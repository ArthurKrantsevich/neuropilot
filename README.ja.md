## これは何？

左にいるのはチャンネルのマスコット **Unit**。キューブでできた、生きている3Dロボットです。浮島の端の丸太に座って足をぶらぶらさせ、画面の顔でカーソルを追い、ホバーしたカードを見てそのテーマを画面に映します。クリックすると感情で反応します。

右には**動画のすべてのコンポーネント**が、すき間のないレイアウトで並びます：

- **閉じた状態** — 番号、タイトル、短い説明；
- **開いた状態** — ページ上でそのまま触れるライブデモ；
- **`</>` コード** — コンポーネントのファイルを表示、**⤓ .zip** — ソースをひとつのアーカイブでダウンロード；
- **▲ / ▼** — コンポーネントを評価；
- **🔒 未公開** — 動画が公開されるまでカードはロックされ、「Unitがまだこのウィジェットを組み立て中」とカウントダウンが表示されます。時間になると自動で開きます。

各カードには直接リンクがあります：`https://arthurkrantsevich.github.io/neuropilot/#<id>` — 動画の説明欄はこれでコンポーネントを指しています。

## しくみ

| 部分 | 場所 | 中身 |
|---|---|---|
| ホーム | [`src/home/BentoHome.tsx`](src/home/BentoHome.tsx) | 独自の時計を持つ3Dシーン（60fpsで描画されるのはそれだけ）＋カード列 |
| カード | [`src/home/Card.tsx`](src/home/Card.tsx) | 開閉、コードウィンドウ、評価、カウントダウン付きのロック状態 |
| レイアウト | [`src/home/Masonry.tsx`](src/home/Masonry.tsx) | 各カードは一番短い列へ；移動はなめらか |
| 公開予定 | [`src/home/releases.ts`](src/home/releases.ts) | コンポーネントが開く時刻；アップロードごとに1行追加 |
| コンポーネント | [`src/gallery/`](src/gallery) | 動画のすべてのデモ；ソースはビルド前に `public/code` へコピー |
| Unitと世界 | [`src/studio/`](src/studio) | ボクセルビルダー、リグ、モーションライブラリ — 動画を描くのと同じコード |

Unitのコードは動画用（Remotion）に書かれており、そこではフレームはフレーム番号です。サイトでは [`src/shims/remotion.tsx`](src/shims/remotion.tsx) がそれをブラウザの実時間に置き換えるので、Unitは動画と同じように動きます。

## ローカルで実行

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # out/ に静的サイト（先にソースを public/code へコピー）
./deploy.sh        # GitHub Pagesに公開（gh-pagesブランチ）
```
