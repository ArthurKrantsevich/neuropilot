## Что это

Слева — **Юнит**, маскот канала: живой 3D-робот из кубиков. Он сидит на бревне на краю парящего острова, болтает ножками, следит экраном за курсором, смотрит на карточку, на которую ты навёл, и показывает на экране её тему. Кликни по нему — ответит эмоцией.

Справа — **все компоненты из роликов** в кладке без пустот:

- **свёрнута** — номер, название, короткое описание;
- **развёрнута** — живое демо, его можно тыкать прямо на странице;
- **`</>` Код** — окно с файлами компонента, **⤓ .zip** — скачать исходники одним архивом;
- **▲ / ▼** — оценка компонента;
- **🔒 ещё не вышел** — пока ролик не опубликован, карточка заперта: «Юнит ещё собирает этот виджет» и таймер до выхода. Открывается сама.

Каждая карточка открывается прямой ссылкой: `https://arthurkrantsevich.github.io/neuropilot/#<id>` — так на компонент ведут описания роликов.

## Как устроено

| Часть | Где | Что внутри |
|---|---|---|
| Главная | [`src/home/BentoHome.tsx`](src/home/BentoHome.tsx) | 3D-сцена со своими часами (60 к/с рисуется только она) + колонка карточек |
| Карточка | [`src/home/Card.tsx`](src/home/Card.tsx) | свёрнута / развёрнута, окно кода, оценки, запертое состояние с таймером |
| Кладка | [`src/home/Masonry.tsx`](src/home/Masonry.tsx) | каждая карточка — в самую короткую колонку; переезды плавные, без пересоздания |
| Выход роликов | [`src/home/releases.ts`](src/home/releases.ts) | когда компонент откроется; строка добавляется при каждой заливке |
| Компоненты | [`src/gallery/`](src/gallery) | все демо из роликов; исходники к ним собираются в `public/code` перед сборкой |
| Юнит и мир | [`src/studio/`](src/studio) | воксельный конструктор, риг, библиотека движений — тот же код, что рисует ролики |

Код Юнита написан под видео (Remotion): там кадр — номер кадра ролика. На сайте его подменяет [`src/shims/remotion.tsx`](src/shims/remotion.tsx) — кадр берётся из живого времени браузера, поэтому Юнит на сайте двигается так же, как в роликах.

## Запустить у себя

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # статический сайт в out/ (перед сборкой исходники компонентов кладутся в public/code)
./deploy.sh        # выложить на GitHub Pages (ветка gh-pages)
```
