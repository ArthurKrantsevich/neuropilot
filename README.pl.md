## Co to jest

Po lewej siedzi **Unit**, maskotka kanału: żywy robot 3D z sześcianów. Siedzi na kłodzie na krawędzi latającej wyspy, macha nogami, śledzi kursor twarzą-ekranem, patrzy na kartę, którą wskazujesz, i pokazuje jej temat. Kliknij go — zareaguje emocją.

Po prawej **wszystkie komponenty z filmów** w murze bez dziur:

- **zwinięta** — numer, tytuł, krótki opis;
- **rozwinięta** — żywe demo do klikania na stronie;
- **`</>` Kod** — okno z plikami komponentu, **⤓ .zip** — pobierz źródła jednym archiwum;
- **▲ / ▼** — oceń komponent;
- **🔒 jeszcze nie wyszedł** — dopóki film nie jest opublikowany, karta jest zablokowana: „Unit wciąż składa ten widżet” i odliczanie. Odblokuje się sama.

Każda karta ma bezpośredni link: `https://arthurkrantsevich.github.io/neuropilot/#<id>` — tak prowadzą do niej opisy filmów.

## Jak to działa

| Część | Gdzie | Co w środku |
|---|---|---|
| Strona główna | [`src/home/BentoHome.tsx`](src/home/BentoHome.tsx) | scena 3D z własnym zegarem (tylko ona rysuje się w 60 kl./s) + kolumna kart |
| Karta | [`src/home/Card.tsx`](src/home/Card.tsx) | zwinięta / rozwinięta, okno kodu, oceny, stan zablokowany z odliczaniem |
| Mur | [`src/home/Masonry.tsx`](src/home/Masonry.tsx) | każda karta trafia do najkrótszej kolumny; płynne przejścia |
| Premiery | [`src/home/releases.ts`](src/home/releases.ts) | kiedy komponent się otworzy; przy każdym uploadzie dochodzi linia |
| Komponenty | [`src/gallery/`](src/gallery) | wszystkie dema z filmów; ich źródła trafiają do `public/code` przed buildem |
| Unit i świat | [`src/studio/`](src/studio) | konstruktor wokseli, rig, biblioteka ruchów — ten sam kod, który renderuje filmy |

Kod Unita napisano pod wideo (Remotion), gdzie klatka to numer klatki. Na stronie [`src/shims/remotion.tsx`](src/shims/remotion.tsx) zastępuje go prawdziwym czasem przeglądarki, więc Unit rusza się jak w filmach.

## Uruchom lokalnie

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # statyczna strona w out/ (najpierw źródła kopiowane są do public/code)
./deploy.sh        # publikacja na GitHub Pages (gałąź gh-pages)
```
