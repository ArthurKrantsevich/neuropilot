## O que é

À esquerda está o **Unit**, mascote do canal: um robô 3D vivo feito de cubos. Ele está sentado num tronco na beira de uma ilha flutuante, balança as pernas, segue o cursor com a tela-rosto, olha para o card que você aponta e mostra o tema dele. Clique nele e ele reage com uma emoção.

À direita, **todos os componentes dos vídeos** num mosaico sem buracos:

- **fechado** — número, título e descrição curta;
- **aberto** — uma demo viva para mexer na própria página;
- **`</>` Código** — janela com os arquivos do componente, **⤓ .zip** — baixe o código num arquivo;
- **▲ / ▼** — avalie o componente;
- **🔒 ainda não saiu** — até o vídeo ser publicado, o card fica trancado: «Unit ainda está montando este widget» e uma contagem regressiva. Destranca sozinho.

Cada card tem link direto: `https://arthurkrantsevich.github.io/neuropilot/#<id>` — é assim que as descrições dos vídeos apontam para ele.

## Como funciona

| Parte | Onde | O que tem |
|---|---|---|
| Início | [`src/home/BentoHome.tsx`](src/home/BentoHome.tsx) | cena 3D com relógio próprio (só ela é desenhada a 60 fps) + coluna de cards |
| Card | [`src/home/Card.tsx`](src/home/Card.tsx) | fechado / aberto, janela de código, votos, estado trancado com contagem |
| Mosaico | [`src/home/Masonry.tsx`](src/home/Masonry.tsx) | cada card vai para a coluna mais curta; movimentos suaves |
| Lançamentos | [`src/home/releases.ts`](src/home/releases.ts) | quando um componente abre; uma linha é adicionada a cada upload |
| Componentes | [`src/gallery/`](src/gallery) | todas as demos dos vídeos; o código vai para `public/code` antes do build |
| Unit e o mundo | [`src/studio/`](src/studio) | construtor de voxels, rig, biblioteca de movimentos — o mesmo código que renderiza os vídeos |

O código do Unit foi escrito para vídeo (Remotion), onde o quadro é o número do quadro. No site, [`src/shims/remotion.tsx`](src/shims/remotion.tsx) troca isso pelo tempo real do navegador, então o Unit se move como nos vídeos.

## Rodar localmente

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # site estático em out/ (antes o código dos componentes vai para public/code)
./deploy.sh        # publicar no GitHub Pages (branch gh-pages)
```
