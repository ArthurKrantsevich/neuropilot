## Bu nedir

Solda kanalın maskotu **Unit** var: küplerden yapılmış canlı bir 3D robot. Uçan bir adanın kenarındaki kütüğe oturmuş, bacaklarını sallıyor, ekran yüzüyle imleci takip ediyor, üzerine geldiğin karta bakıp temasını ekranında gösteriyor. Ona tıkla, bir duyguyla karşılık versin.

Sağda **videolardaki tüm bileşenler** boşluksuz bir düzende:

- **kapalı** — numara, başlık, kısa açıklama;
- **açık** — sayfada oynayabileceğin canlı demo;
- **`</>` Kod** — bileşenin dosyalarını gösteren pencere, **⤓ .zip** — kaynakları tek arşivde indir;
- **▲ / ▼** — bileşeni puanla;
- **🔒 henüz çıkmadı** — video yayınlanana kadar kart kilitli: “Unit bu bileşeni hâlâ yapıyor” ve geri sayım. Kendiliğinden açılır.

Her kartın doğrudan bağlantısı var: `https://arthurkrantsevich.github.io/neuropilot/#<id>` — video açıklamaları bileşene böyle bağlanır.

## Nasıl çalışır

| Bölüm | Nerede | İçinde ne var |
|---|---|---|
| Ana sayfa | [`src/home/BentoHome.tsx`](src/home/BentoHome.tsx) | kendi saati olan 3D sahne (60 fps'de yalnızca o çizilir) + kart sütunu |
| Kart | [`src/home/Card.tsx`](src/home/Card.tsx) | kapalı / açık, kod penceresi, oylar, geri sayımlı kilitli durum |
| Düzen | [`src/home/Masonry.tsx`](src/home/Masonry.tsx) | her kart en kısa sütuna gider; geçişler yumuşak |
| Yayınlar | [`src/home/releases.ts`](src/home/releases.ts) | bileşenin ne zaman açılacağı; her yüklemede bir satır eklenir |
| Bileşenler | [`src/gallery/`](src/gallery) | videolardaki tüm demolar; kaynakları derlemeden önce `public/code`'a kopyalanır |
| Unit ve dünyası | [`src/studio/`](src/studio) | voksel kurucu, rig, hareket kütüphanesi — videoları çizen kodun aynısı |

Unit'in kodu video (Remotion) için yazıldı; orada kare, karenin numarasıdır. Sitede [`src/shims/remotion.tsx`](src/shims/remotion.tsx) bunu tarayıcının gerçek zamanıyla değiştirir, böylece Unit videolardaki gibi hareket eder.

## Yerelde çalıştır

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # out/ içinde statik site (önce kaynaklar public/code'a kopyalanır)
./deploy.sh        # GitHub Pages'e yayınla (gh-pages dalı)
```
