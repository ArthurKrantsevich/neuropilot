## Що це

Ліворуч — **Юніт**, маскот каналу: живий 3D-робот із кубиків. Він сидить на колоді на краю летючого острова, бовтає ніжками, стежить екраном за курсором, дивиться на картку, на яку ти навів, і показує на екрані її тему. Клікни по ньому — відповість емоцією.

Праворуч — **усі компоненти з роликів** у кладці без порожнин:

- **згорнута** — номер, назва, короткий опис;
- **розгорнута** — живе демо, його можна тицяти просто на сторінці;
- **`</>` Код** — вікно з файлами компонента, **⤓ .zip** — завантажити сирці одним архівом;
- **▲ / ▼** — оцінка компонента;
- **🔒 ще не вийшов** — поки ролик не опубліковано, картка замкнена: «Юніт ще збирає цей віджет» і таймер до виходу. Відкривається сама.

Кожна картка відкривається прямим посиланням: `https://arthurkrantsevich.github.io/neuropilot/#<id>` — так на компонент ведуть описи роликів.

## Як влаштовано

| Частина | Де | Що всередині |
|---|---|---|
| Головна | [`src/home/BentoHome.tsx`](src/home/BentoHome.tsx) | 3D-сцена зі своїм годинником (60 к/с малюється лише вона) + колонка карток |
| Картка | [`src/home/Card.tsx`](src/home/Card.tsx) | згорнута / розгорнута, вікно коду, оцінки, замкнений стан із таймером |
| Кладка | [`src/home/Masonry.tsx`](src/home/Masonry.tsx) | кожна картка — у найкоротшу колонку; переїзди плавні |
| Вихід роликів | [`src/home/releases.ts`](src/home/releases.ts) | коли компонент відкриється; рядок додається з кожним завантаженням |
| Компоненти | [`src/gallery/`](src/gallery) | усі демо з роликів; сирці до них збираються в `public/code` перед збиранням |
| Юніт і світ | [`src/studio/`](src/studio) | воксельний конструктор, риг, бібліотека рухів — той самий код, що малює ролики |

Код Юніта написано під відео (Remotion): там кадр — номер кадру ролика. На сайті його підміняє [`src/shims/remotion.tsx`](src/shims/remotion.tsx) — кадр береться з живого часу браузера, тож Юніт рухається так само, як у роликах.

## Запустити в себе

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # статичний сайт в out/ (перед збиранням сирці компонентів кладуться в public/code)
./deploy.sh        # викласти на GitHub Pages (гілка gh-pages)
```
